# Budget Planner CLI

A Python terminal app that helps users track income, expenses, due dates, savings rate, weekly set-aside money, and remaining spending money.

## Features
- Add income sources
- Add expenses with due dates
- Convert weekly, biweekly, and monthly income
- Calculate days until bills are due
- Calculate weekly set-aside amount
- Choose a savings rate
- Generate weekly and monthly budget summaries

## Tech Used
- Python
- datetime
- Functions
- Lists
- Loops
- Conditionals
- Input validation

## How to Run

```bash
python3 main.py
